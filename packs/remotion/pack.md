# Pack: remotion

An opt-in extra. It installs the third-party `remotion-best-practices` skill at
`.claude/skills/remotion-best-practices/`, fetched from GitHub at the commit pinned in `pack.json` and checked
against its sha256; the kit never copies it. It extends no core command and has no facts of its own.
